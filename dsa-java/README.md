# DSA solutions (verified)

One self-contained Java file per DSA lesson (`src/content/dsa/**`). Each file contains the lesson's
solutions and a `main` that tests them — usually against a brute-force version on thousands of
random inputs.

```bash
./dsa-java/run-all.sh                               # everything
java dsa-java/two-pointers/TwoPointers.java         # one lesson
```

Requires JDK 21+. The lessons show the same code; when you change one, change the other and rerun.
